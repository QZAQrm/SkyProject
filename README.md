# SkyProject
Проект на Python, представляющий собой виджет для обработки банковских операций клиента.

## Описание
Проект включает в себя функции для:
- Маскировки номеров банковских карт и счетов.
- Форматирования дат операций.
- Фильтрации словарей по статусу и сортировки по дате.

## Инструкция по использованию
Клонируйте репозиторий на свой компьютер. 
Проект использует менеджер зависимостей Poetry. Для установки всех необходимых линтеров и зависимостей выполните команду `poetry install`. 
Вся основная логика находится в пакете `src`.
